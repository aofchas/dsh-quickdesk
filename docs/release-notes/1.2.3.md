# QuickDesk 1.2.3 发布说明 / Release notes

## 中文

> 发布日期：2026-11-14

### 新增

- **五个快捷键都支持直接按键录入**：呼出、提交、取消、审批通过、审批拒绝都可以点击
  「按下组合键…」后录入。支持单键（字母、数字、Enter、Backspace、Esc、F1–F24 等）
  和 Ctrl/Alt/Shift 组合。
- **冲突处理**：`submit/cancel` 或 `approve/reject` 相同时阻止保存，并提供
  「交换两者」；呼出快捷键与其它快捷键冲突时阻止保存，不提供交换。
  `submit=Enter` 与 `approve=Enter` 这类跨上下文共享继续允许。
- **高风险单键提示**：呼出快捷键设为裸字母/数字，或提交/取消键设为裸字母/数字/Space
  时给出非阻断提示。
- **系统级注册失败提示**：保存后如果系统已占用呼出快捷键，sidecar 注册失败会显示在
  HUD 和 `launcher.log` 中。

### 修复

- 录制快捷键时 **Esc 不再被强制当作“取消录制”**；Esc 现在是普通可录入按键，
  因此取消键可以重新设置为 Esc。取消录制请再次点击按钮或点击别处。
- 呼出快捷键的提示语已改为和其它快捷键一致，不再单独写“点击‘按下组合键’…”。
- 移除未实际实现的 **Win** 修饰键声明；快捷键范围为 Ctrl/Alt/Shift。

### 兼容性

- DSH Desktop 0.2.2-rc.3 实测通过；支持 `web` / `desktop` profile。
- Windows 10/11、PowerShell 5.1；仍需 `dsh-computer-use-win` 或其它桌面工具后端。
- 除快捷键录入/冲突处理和相应提示外，运行行为与 1.2.2 一致。

### 安装 / 升级

```powershell
dsh plugin --profile web add dsh-quickdesk@1.2.3
```

升级后请完全退出并重启 DSH。已有配置会保留；设置页五个快捷键旁都有
「按下组合键…」按钮。

## English

> Released: 2026-11-14

### Added

- **All five shortcuts support press-to-capture**: summon, submit, cancel, approve
  and reject. Click “Press shortcut…” and press a single key (letters, digits,
  Enter, Backspace, Esc, F1–F24, etc.) or a Ctrl/Alt/Shift combination.
- **Conflict handling**: `submit/cancel` or `approve/reject` conflicts block
  saving and offer “Swap both”; a summon-hotkey conflict blocks saving without a
  swap. Cross-context duplicates remain allowed, including
  `submit=Enter` with `approve=Enter`.
- **Risky single-key warnings**: non-blocking warnings when the summon key is a
  bare letter/digit, or when submit/cancel is a bare letter/digit/Space.
- **System-level registration warning**: if another app already owns the summon
  hotkey, sidecar registration failure is shown in the HUD and `launcher.log`.

### Fixed

- **Esc is no longer forced to cancel capture**. It is now a normal capturable
  key, so the cancel key can be set back to Esc. Cancel recording by clicking the
  capture button again or clicking elsewhere.
- The summon-hotkey hint now matches the other shortcut hints instead of saying
  “Click ‘Press shortcut…’…”.
- Removed the **Win** modifier claim; the supported range is Ctrl/Alt/Shift.

### Compatibility

- Verified with DSH Desktop 0.2.2-rc.3; supports the `web` and `desktop`
  profiles.
- Windows 10/11, PowerShell 5.1; still requires `dsh-computer-use-win` or
  another desktop-tool provider.
- Runtime behavior is unchanged from 1.2.2 apart from shortcut capture, conflict
  handling and the related warnings.

### Install / upgrade

```powershell
dsh plugin --profile web add dsh-quickdesk@1.2.3
```

Fully quit and restart DSH after upgrading. Existing settings are preserved; all
five shortcut fields now have a “Press shortcut…” button.
