# QuickDesk 1.2.4 发布说明 / Release notes

## 中文

> 发布日期：2026-11-14

### 更新

- 整理文档与包元数据，无功能变化。

### 兼容性

- DSH Desktop 0.2.2-rc.3 实测通过；支持 `web` / `desktop` profile。
- Windows 10/11、PowerShell 5.1；仍需 `dsh-computer-use-win` 或其它桌面工具后端。

### 安装 / 升级

```powershell
dsh plugin --profile web add dsh-quickdesk@1.2.4
```

升级后请完全退出并重启 DSH。已有配置会保留。

## English

> Released: 2026-11-14

### Updated

- Documentation and package metadata cleanup. No functional changes.

### Compatibility

- Verified with DSH Desktop 0.2.2-rc.3; supports the `web` and `desktop` profiles.
- Windows 10/11, PowerShell 5.1; still requires `dsh-computer-use-win` or another desktop-tool provider.

### Install / upgrade

```powershell
dsh plugin --profile web add dsh-quickdesk@1.2.4
```

Fully quit and restart DSH after upgrading. Existing settings are preserved.
