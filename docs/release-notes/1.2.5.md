# QuickDesk 1.2.5 发布说明 / Release notes

## 中文

> 发布日期：2026-11-17

### 新增

- **多步任务先拆解**：任务需要多个可见步骤时，QuickDesk 的任务协议会要求 Agent 先调用 `todo_write` 记录 2–6 个具体步骤，再按顺序执行并更新状态。
- 一步就能完成的任务会自动跳过规划，不额外创建 Todo。
- 设置页新增「多步任务先拆解再执行」开关，默认开启；配置字段为 `planFirst`。
- 规划过程不向用户展示，最终仍保持「完成即停、只回一行结果」的原有行为。

### 兼容性

- DSH Desktop 0.2.2-rc.3 实测通过；支持 `web` / `desktop` profile。
- Windows 10/11、PowerShell 5.1；仍需 `dsh-computer-use-win` 或其它桌面工具后端。
- 如果当前 Agent 预设没有 `todo_write`，任务会退化为内部简短规划，不影响执行。

### 安装 / 升级

```powershell
dsh plugin --profile web add dsh-quickdesk@1.2.5
```

升级后请完全退出并重启 DSH。已有配置会保留。

## English

> Released: 2026-11-17

### Added

- **Plan multi-step tasks first**: when a task needs several visible steps, QuickDesk’s protocol asks the agent to call `todo_write` with 2–6 concrete steps, then execute them in order and update each status.
- One-step tasks skip planning and do not create a todo list.
- New Settings toggle “Plan multi-step tasks first”, enabled by default; the config field is `planFirst`.
- The plan stays internal and the existing “stop when done, reply with one line” behavior is preserved.

### Compatibility

- Verified with DSH Desktop 0.2.2-rc.3; supports the `web` and `desktop` profiles.
- Windows 10/11, PowerShell 5.1; still requires `dsh-computer-use-win` or another desktop-tool provider.
- If the active agent preset has no `todo_write`, the task falls back to a short internal plan without blocking execution.

### Install / upgrade

```powershell
dsh plugin --profile web add dsh-quickdesk@1.2.5
```

Fully quit and restart DSH after upgrading. Existing settings are preserved.
