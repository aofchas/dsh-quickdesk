# QuickDesk 1.2.1 发布说明 / Release notes

## 中文

> 发布日期：2026-11-14

### 修复

- **中文 Windows（GB2312/936 代码页）上热键完全失效**：`launcher.ps1` 和
  `approval-popup.ps1` 之前含 UTF-8 中文兜底文案；Windows PowerShell 5.1 会把
  无 BOM 的 UTF-8 脚本按系统 ANSI 代码页读取，在中文 Windows 上解析失败，
  sidecar 在建日志之前就退出，因此全局热键没有任何反应。1.2.1 把两个脚本改为
  纯 ASCII，兜底文案改成英文；正常界面文案仍由宿主按语言注入。
- 新增发布门禁：任何 `.ps1`/`.cmd` 出现非 ASCII 字节，或 GB2312 读取模拟下解析
  失败，`npm test` / `npm publish` 都会失败。

### 新增

- **设置页一键诊断**：设置 → QuickDesk → 诊断与支持 → 运行诊断。可以选择报告
  保存位置（原生另存为对话框）；报告生成后会自动删除临时收集目录。报告包含
  环境、DSH profile、QuickDesk 日志、sidecar 状态、PowerShell 前置条件和 DSH
  日志摘要，便于反馈问题。
- 双语 GitHub Release 说明成为发版要求：每个版本必须提供
  `docs/release-notes/<version>.md`，Release workflow 会把它作为 Release 正文。

### 兼容性

- DSH Desktop 0.2.2-rc.3 实测通过；支持 `web` / `desktop` profile。
- Windows 10/11、PowerShell 5.1；仍需 `dsh-computer-use-win` 或其它桌面工具后端。

### 安装 / 升级

```powershell
dsh plugin --profile web add dsh-quickdesk@1.2.1
```

升级后请完全退出并重启 DSH。已有配置会保留；设置页新增“诊断与支持”区块。

## English

> Released: 2026-11-14

### Fixed

- **Global hotkey was dead on Chinese Windows (GB2312/936 code page)**:
  `launcher.ps1` and `approval-popup.ps1` contained UTF-8 Chinese fallback
  strings. Windows PowerShell 5.1 reads BOM-less UTF-8 scripts using the system
  ANSI code page, so parsing failed on a fresh Chinese Windows machine and the
  sidecar exited before writing `launcher.log`; the hotkey never worked. 1.2.1
  makes both scripts pure ASCII with English fallbacks; normal localized UI text
  is still injected by the Host.
- New publish gate: `npm test` / `npm publish` fail if any `.ps1`/`.cmd` contains
  non-ASCII bytes or fails the GB2312 parser simulation.

### Added

- **One-click diagnostics in Settings → QuickDesk → Diagnostics and support.**
  A native Save-As dialog lets the user choose where to save the report zip; the
  temporary collection folder is deleted after a successful zip. The report
  includes the environment, DSH profiles, QuickDesk logs, sidecar state,
  PowerShell prerequisites and recent DSH log excerpts.
- Bilingual GitHub Release notes are now a release requirement: each version
  must provide `docs/release-notes/<version>.md`, which the release workflow
  uses as the Release body.

### Compatibility

- Verified with DSH Desktop 0.2.2-rc.3; supports the `web` and `desktop`
  profiles.
- Windows 10/11, PowerShell 5.1; still requires `dsh-computer-use-win` or
  another desktop-tool provider.

### Install / upgrade

```powershell
dsh plugin --profile web add dsh-quickdesk@1.2.1
```

Fully quit and restart DSH after upgrading. Existing settings are preserved; the
settings page gains the new "Diagnostics and support" section.
