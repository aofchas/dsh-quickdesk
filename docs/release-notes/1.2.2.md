# QuickDesk 1.2.2 发布说明 / Release notes

## 中文

> 发布日期：2026-11-14

### 新增

- **设置页直接按键录入呼出快捷键**：在「呼出快捷键」右侧点击「按下组合键…」，
  然后按下想要的组合键即可自动填入；只按 Ctrl/Shift/Alt 不会改值，Esc 取消，
  录入结果仍走原有格式校验。新增 `scripts/tests/client-hotkey.test.mjs` 覆盖
  组合键格式化、验证、修饰键过滤和 Esc 取消。

### 修复

- 发布包不再包含维护者内部资料：`docs/PUBLISHING.md`、`docs/TESTING.md`、
  `docs/market-copy.md`、`docs/release-notes/`，以及 `scripts/selftest.mjs`、
  `scripts/verify-release.mjs` 等维护者脚本。`npm pack` 和测试会拦截这类文件。
- README 不再把默认 `Ctrl+Alt+Space` 写成唯一的呼出方式，改为“按配置的呼出快捷键
  （默认 Ctrl+Alt+Space）”；中英文都增加了快速开始。
- CHANGELOG、COMPATIBILITY 和 README 不再暴露 1.2 之前的内部版本里程碑，公开
  变更记录从 1.2.0 开始。

### 兼容性

- DSH Desktop 0.2.2-rc.3 实测通过；支持 `web` / `desktop` profile。
- Windows 10/11、PowerShell 5.1；仍需 `dsh-computer-use-win` 或其它桌面工具后端。
- 除快捷键录入和文档/打包清理外，运行行为与 1.2.1 一致。

### 安装 / 升级

```powershell
dsh plugin --profile web add dsh-quickdesk@1.2.2
```

升级后请完全退出并重启 DSH。已有配置会保留；设置页的呼出快捷键旁新增
「按下组合键…」按钮。

## English

> Released: 2026-11-14

### Added

- **Capture the global hotkey by pressing it in Settings**: click “Press shortcut…”
  next to the Hotkey field and press the desired combination; the validated spec
  is filled in automatically. Modifier-only presses do nothing, Esc cancels, and
  the result still goes through the existing validation.
  `scripts/tests/client-hotkey.test.mjs` covers formatting, validation,
  modifier filtering and Esc cancellation.

### Fixed

- The published package no longer contains maintainer-only documentation
  (`docs/PUBLISHING.md`, `docs/TESTING.md`, `docs/market-copy.md`, release notes)
  or maintainer scripts (`selftest.mjs`, `verify-release.mjs`). `npm pack` and
  the test suite reject those files.
- README no longer presents the default `Ctrl+Alt+Space` as the only way to
  summon QuickDesk; it now says “press your configured hotkey (defaults to
  Ctrl+Alt+Space)”. Both Chinese and English quick starts are present.
- CHANGELOG, COMPATIBILITY and README no longer expose pre-1.2 internal
  milestones; the public history starts at 1.2.0.

### Compatibility

- Verified with DSH Desktop 0.2.2-rc.3; supports the `web` and `desktop`
  profiles.
- Windows 10/11, PowerShell 5.1; still requires `dsh-computer-use-win` or
  another desktop-tool provider.
- Runtime behavior is unchanged from 1.2.1 apart from hotkey capture and the
  documentation/package cleanup.

### Install / upgrade

```powershell
dsh plugin --profile web add dsh-quickdesk@1.2.2
```

Fully quit and restart DSH after upgrading. Existing settings are preserved; the
settings page gains a “Press shortcut…” button next to the Hotkey field.
